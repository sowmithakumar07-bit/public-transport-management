SCENARIO 1: EXECUTE CUSTOM SQL QUERY
----------------------------------------------------------------------------
Menu Choice: 1
Sample Query 1:
SELECT BusID, BusNumber, Capacity, BusType, Status FROM Bus WHERE Status = 'Active';

Sample Query 2:
SELECT r.Source, r.Destination, COUNT(b.BookingID) AS TotalBookings, SUM(b.TotalFare) AS Revenue
FROM Route r
JOIN Schedule s ON r.RouteID = s.RouteID
JOIN Booking b ON s.ScheduleID = b.ScheduleID
WHERE b.Status = 'Confirmed'
GROUP BY r.RouteID, r.Source, r.Destination
ORDER BY Revenue DESC;

Sample Query 3 (Nested Subquery):
SELECT ScheduleID, BusID, Fare FROM Schedule WHERE Fare > (SELECT AVG(Fare) FROM Schedule);
